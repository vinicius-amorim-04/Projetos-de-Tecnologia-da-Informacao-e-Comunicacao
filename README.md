# 📡 Projetos de Tecnologia da Informação e Comunicação (PTIC)

## 📚 Sobre

Nesta disciplina, aprendi os fundamentos de **planejamento, organização e gerenciamento de projetos relacionados à tecnologia da informação e comunicação**.

Durante os estudos, explorei conceitos de gestão de projetos, análise de requisitos, metodologias ágeis, gerenciamento de riscos e comunicação entre equipes.

---

## 🧠 O que aprendi

| Área                      | Conhecimentos                                           |
| ------------------------- | ------------------------------------------------------- |
| 📋 **Planejamento**       | Organização e estruturação de projetos de TI            |
| 🎯 **Objetivos**          | Definição de metas, prazos e recursos                   |
| 🔄 **Metodologias ágeis** | Scrum, Kanban e organização de tarefas                  |
| ⚠️ **Gestão de riscos**   | Identificação e acompanhamento de possíveis problemas   |
| 📊 **Resultados**         | Monitoramento e avaliação do andamento dos projetos     |
| 🤝 **Trabalho em equipe** | Comunicação e colaboração em projetos tecnológicos      |
| 📝 **Requisitos**         | Identificação e organização das necessidades do projeto |

---

## 🛠️ Principais conceitos

`Gestão de Projetos` • `Scrum` • `Kanban` • `Análise de Requisitos` • `Gestão de Riscos` • `Planejamento` • `Trabalho em Equipe`
